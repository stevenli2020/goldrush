# L4-004 — 10Y Breakeven Inflation

Parses FRED `T10YIE` daily 10-year breakeven inflation observations in percentage points. This is a market-implied proxy, not a survey forecast.

Run: `python parser.py --raw ../../data/macro/raw/fred/T10YIE-<timestamp>.json --output data/processed/L4_004_observations.csv`
