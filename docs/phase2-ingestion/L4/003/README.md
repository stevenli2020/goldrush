# L4-003 — 5Y Breakeven Inflation

Parses FRED `T5YIE` daily 5-year breakeven inflation observations in percentage points. This is a market-implied proxy, not a survey forecast.

Run: `python parser.py --raw ../../data/macro/raw/fred/T5YIE-<timestamp>.json --output data/processed/L4_003_observations.csv`
