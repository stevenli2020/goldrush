# L8-001 Phase 3 handoff

The WGC ETF workbook's per-fund `Demand (tonnes)` values from `Demand by month`
are summed as deterministic monthly changes in ETF gold holdings. Negative
values are valid net outflows; the series is distinct from ETF holdings as a
stock. The aggregate `Tonnes` column in `Fund flows by month` is not used. No
GLD/IAU market proxy or synthetic flow is introduced.
