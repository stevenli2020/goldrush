# L5-006 Phase 3 handoff

The operational label remains **Official-Sector Gold Sales / Lending** for
continuity, but the canonical interpretation is **official-sector net
reduction proxy**. Phase 4 must not treat the output as a separately measured
sales or lending series.

The WGC official-changes workbook is represented as positive metric-tonne
values for negative canonical country changes. This is an official-sector net
reduction proxy: the workbook does not identify lending separately and does
not support an outright-sale estimate. Possible causes include sales, lending,
swaps, reporting adjustments, or other reductions. Starred alternative/gross
series are excluded by Phase 2; no synthetic values are introduced.
