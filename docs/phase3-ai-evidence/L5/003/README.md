# L5-003 Phase 3 handoff

IMF COFER world aggregate `G001.AFXRA.CI_USD.SHRO_PT.Q` is represented as the
quarter-on-quarter change in the published U.S.-dollar share of allocated
foreign-exchange reserves, in percentage points. The initial valid quarter has
no prior quarter and therefore carries a null change; no missing quarter is
manufactured. This is a revised reserve-composition indicator, not a gold-flow
measure.
