# L9-001 Phase 3 handoff

The official World Gold Council Chinese premium/discount workbook is passed
through as a deterministic USD-per-troy-ounce difference between theoretical
local and international gold prices. Positive and negative values are both
valid. Workbook dates and WGC’s published five-day moving-average definition
are retained; no SGE, FX, COMEX, or LBMA replacement calculation is introduced.
