# L9-004 Phase 3 handoff

The WGC GDT India rows are passed through as separate metric-tonne observations
for jewellery demand, bar-and-coin demand, gross bullion imports, and net
bullion imports. Annual and quarterly records remain distinct even when their
dates coincide. `India Supply` is a WGC/Metals Focus estimate, not a separately
reconciled customs series; no combined demand/import inference is made.
