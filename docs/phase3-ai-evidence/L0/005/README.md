# L0-005 — Bar-and-Coin Investment Holdings / Demand

Phase 3 uses the live WGC Gold Demand Trends workbook and the approved Phase 2
parser. The canonical value is total bar-and-coin demand in metric tonnes,
preserving annual or quarterly observation periods. Parser quality flags remain
visible in the handoff. Duplicate periods, failed observations, and unavailable
data are rejected; no substitute value is used.
